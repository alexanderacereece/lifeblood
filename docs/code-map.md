# Code map

Every package and class in `src/main/java/lifeblood`, with the first sentence of its doc comment. **Generated by `CodeMapTest` on every build; don't edit it by hand.** To change a line, change the doc comment.

Search this before writing anything new: if something close already exists, use it or extend it. How the pieces fit together is in [architecture.md](architecture.md).

## `lifeblood`

The mod itself: its entry point (Lifeblood), its settings (NpcConfig), and ClientHooks, the only way common code asks the client for anything.

- [`ClientHooks`](../src/main/java/lifeblood/ClientHooks.java): Everything common code asks of the client, in one place: opening screens and refreshing textures.
- [`Lifeblood`](../src/main/java/lifeblood/Lifeblood.java): The mod's entry point, started by Fabric on both client and server: loads the settings, registers the NPC entity, the items and the /lb command.
- [`Mod`](../src/main/java/lifeblood/Mod.java): The mod's id and its log, for any code to use.
- [`NpcConfig`](../src/main/java/lifeblood/NpcConfig.java): The mod's settings, in config/lifeblood.cfg: item ids (changeable if they clash with another mod's) and game settings.
- [`Systems`](../src/main/java/lifeblood/Systems.java): Every system's setup, in one ordered list: the one place that shows everything wired into the mod.

## `ai`

The brain: which behavior an NPC runs each tick, the registry of behaviors that can be saved, and the NPC's home.

- [`AiSetup`](../src/main/java/lifeblood/ai/AiSetup.java): The plain orders (go somewhere, stay, wander) and the default daily routine of wandering about home all day.
- [`NpcBehavior`](../src/main/java/lifeblood/ai/NpcBehavior.java): One thing an NPC can be doing.
- [`NpcBehaviors`](../src/main/java/lifeblood/ai/NpcBehaviors.java): The behaviors NPCs can have: orders by id (so a saved NPC gets its orders back when it loads), and instincts, which every NPC is born with.
- [`NpcBrain`](../src/main/java/lifeblood/ai/NpcBrain.java): Picks which behavior an NPC runs each tick: the highest-priority one that can run.
- [`NpcHome`](../src/main/java/lifeblood/ai/NpcHome.java): The spot an NPC calls home: where "stay" stands, what "wander" circles, where a downed NPC recovers, and where it's brought back to if it falls out of the world.

## `ai/behavior`

The plain orders anyone can give an NPC: go somewhere, stay, wander.

- [`GoToBehavior`](../src/main/java/lifeblood/ai/behavior/GoToBehavior.java): Walks to a spot, then stays there (it becomes the NPC's new home).
- [`StayBehavior`](../src/main/java/lifeblood/ai/behavior/StayBehavior.java): Stands at the NPC's home position, walking back if pushed away.
- [`WanderBehavior`](../src/main/java/lifeblood/ai/behavior/WanderBehavior.java): Strolls to random spots within a radius of the NPC's home, pausing between walks.

## `ai/routine`

Daily routines: the schedule of activities an NPC follows when nobody has given it orders.

- [`NpcRoutine`](../src/main/java/lifeblood/ai/routine/NpcRoutine.java): What an NPC does with its day when nobody has told it to do anything: its schedule names an activity for each hour, and the routine keeps a behavior running for the activity of the moment.
- [`Routines`](../src/main/java/lifeblood/ai/routine/Routines.java): The activities NPCs can fill their days with, and the schedules that arrange them.
- [`Schedule`](../src/main/java/lifeblood/ai/routine/Schedule.java): A daily plan: which activity runs from which hour.

## `appearance`

How NPCs look: appearance parts and palettes, hair color and graying, clothes for a gender, climate or job, whole skin files, and slim or wide arms.

- [`Appearance`](../src/main/java/lifeblood/appearance/Appearance.java): Which part (and which palette) an NPC wears on each layer.
- [`AppearanceLayer`](../src/main/java/lifeblood/appearance/AppearanceLayer.java): The layers an NPC's look is built from, in drawing order (later layers draw over earlier ones).
- [`HairColor`](../src/main/java/lifeblood/appearance/HairColor.java): Someone's hair color: the natural color they were born with, how far it has grayed with age, and a dye, if they dye it.
- [`NpcLooks`](../src/main/java/lifeblood/appearance/NpcLooks.java): How one NPC looks: a skin file from npc_skins, or else a look built from appearance parts, and the arm width it's drawn with.
- [`NpcSkinFiles`](../src/main/java/lifeblood/appearance/NpcSkinFiles.java): The npc_skins folder in the game directory.
- [`PartCatalog`](../src/main/java/lifeblood/appearance/PartCatalog.java): Every appearance part and palette available: the ones bundled with the mod (assets/lifeblood/parts/) plus the ones in the game folder's npc_parts/, which can be added to without rebuilding.
- [`SkinModel`](../src/main/java/lifeblood/appearance/SkinModel.java): Which arm width an NPC's skin is drawn with.
- [`SlimArms`](../src/main/java/lifeblood/appearance/SlimArms.java): Turns a 64x64 skin's 4-pixel-wide arms into slim 3-pixel ones, so one wide part (a base body, a shirt) fits slim NPCs too.
- [`Wearer`](../src/main/java/lifeblood/appearance/Wearer.java): Who a look is rolled for, as far as clothes go: their gender, their job (null for none) and the climate they dress for ("cold", "mild", "hot", or null if unknown).

## `brawl`

Fistfights: picking one, fighting it, and telling a brawl punch from a real attack.

- [`Brawl`](../src/main/java/lifeblood/brawl/Brawl.java): A non-lethal fistfight between two people (NPCs or a player and an NPC).
- [`BrawlBehavior`](../src/main/java/lifeblood/brawl/BrawlBehavior.java): Fists up: walks at the other brawler and punches them.
- [`BrawlSetup`](../src/main/java/lifeblood/brawl/BrawlSetup.java): Brawling, as an instinct every NPC has.
- [`NpcBrawling`](../src/main/java/lifeblood/brawl/NpcBrawling.java): Fistfights: picking them, being in one, and telling a brawl punch apart from a real attack (a friend's shove, a cheap shot after the brawl is over, someone reaching for a weapon).

## `building`

Builds: prefabs saved from the world and placed back, turned and with local materials and faction colors.

- [`BlockTurns`](../src/main/java/lifeblood/building/BlockTurns.java): Turns a block's metadata along with a prefab, so stairs, doors, torches, logs and the rest still face the right way.
- [`FacingRule`](../src/main/java/lifeblood/building/FacingRule.java): How one kind of block stores its facing in metadata, and so how to turn it.
- [`LocalMaterials`](../src/main/java/lifeblood/building/LocalMaterials.java): Finds out what a place is made of by looking at it, the way a settler would: which trees grow nearby and which stone is underground.
- [`Prefab`](../src/main/java/lifeblood/building/Prefab.java): A saved build: every block in a box, exactly as it was.
- [`PrefabCapture`](../src/main/java/lifeblood/building/PrefabCapture.java): Copies a box of the world into a Prefab, and finds blocks again by the names prefabs save them under.
- [`PrefabCheck`](../src/main/java/lifeblood/building/PrefabCheck.java): The checks run on a prefab when it's saved, so problems are fixed by whoever builds it rather than found later in the world: parts of two-block things cut off by the box, blocks whose facing won't turn, and a summary of what will be swapped where it's placed.
- [`PrefabFiles`](../src/main/java/lifeblood/building/PrefabFiles.java): The npc_prefabs folder in the game directory, next to npc_parts and npc_skins: one compressed NBT file per prefab, named after it ("cabin.prefab").
- [`PrefabPlacer`](../src/main/java/lifeblood/building/PrefabPlacer.java): Puts a Prefab into the world all at once, turned and with its materials swapped.
- [`StoneFamily`](../src/main/java/lifeblood/building/StoneFamily.java): The kinds of stone that differ from place to place, each with the same set of cut and built forms.
- [`Swaps`](../src/main/java/lifeblood/building/Swaps.java): What a prefab's materials become where it's placed.
- [`Turns`](../src/main/java/lifeblood/building/Turns.java): Quarter turns clockwise, seen from above (north, east, south, west), and what they do to positions and directions.
- [`WoodType`](../src/main/java/lifeblood/building/WoodType.java): The kinds of wood that grow in different places, and the planks each makes.

## `client`

Everything that only exists on the client: rendering, textures and screens.

- [`AppearanceTextures`](../src/main/java/lifeblood/client/AppearanceTextures.java): Builds an NPC's skin from its appearance: each layer's part, recolored with its palette, drawn over the ones before it.
- [`LifebloodClient`](../src/main/java/lifeblood/client/LifebloodClient.java): The client side of the mod, started by Fabric on the client only: renderers, item icons, and the ClientHooks through which common code opens screens and refreshes textures.
- [`NpcDialogueScreen`](../src/main/java/lifeblood/client/NpcDialogueScreen.java): RPG-style conversation: the NPC's line in a box along the bottom of the screen, the player's replies listed on the right.
- [`NpcInventoryScreen`](../src/main/java/lifeblood/client/NpcInventoryScreen.java): The NPC's inventory, styled after the player's own inventory screen: armor column and a live preview of the NPC, then its pack with the hand slot first on the bottom row, then the player's inventory.
- [`NpcProfileScreen`](../src/main/java/lifeblood/client/NpcProfileScreen.java): What the NPC is like, laid out on one page: its eight traits as sliders between their poles, its quirks, what it loves and hates (once the player has heard about them), and how it feels right now and why.
- [`NpcRenderer`](../src/main/java/lifeblood/client/NpcRenderer.java): Draws NPCs with the full player model (hat, jacket, sleeves and pant layers included), plus worn armor and the held item, borrowing the player's model mappings and the human mob's rendering transform.
- [`NpcSkins`](../src/main/java/lifeblood/client/NpcSkins.java): Loads NPC skins from the npc_skins folder and turns them into textures.
- [`TextEntryScreen`](../src/main/java/lifeblood/client/TextEntryScreen.java): Asks the player to type something (a word for an NPC to learn): the question, a hint about what kind of answer fits, a text box with any lead-in words before it ("a ___"), and Done / Cancel, plus an optional extra button (like "Can't count it").
- [`WordBookScreen`](../src/main/java/lifeblood/client/WordBookScreen.java): The word book: every word players have taught, newest first, a page at a time.

## `combat`

Real fights: fight or flight, sizing up danger, melee and archery by the player's rules, and mobs targeting NPCs.

- [`CombatBehavior`](../src/main/java/lifeblood/combat/CombatBehavior.java): Fight or flight.
- [`CombatSetup`](../src/main/java/lifeblood/combat/CombatSetup.java): Fight or flight, as an instinct every NPC has.
- [`CombatStyle`](../src/main/java/lifeblood/combat/CombatStyle.java): How an NPC prefers to fight.
- [`MonsterContact`](../src/main/java/lifeblood/combat/MonsterContact.java): Damage that monsters deal by touch, which vanilla only applies to players.
- [`NpcArchery`](../src/main/java/lifeblood/combat/NpcArchery.java): Bow use for NPCs, matching the player's bow (ItemBow.onUse): the same ammo order (worn quiver, golden quiver, flaming, golden, then plain arrows from the inventory), the same arrows, launch speed and spread, and the same bow wear.
- [`NpcAttackers`](../src/main/java/lifeblood/combat/NpcAttackers.java): Who last attacked the NPC for real, and how it takes being hit: a person who hits it is remembered, and someone it wasn't fighting gets a complaint.
- [`NpcMelee`](../src/main/java/lifeblood/combat/NpcMelee.java): Hand-to-hand fighting by the player's rules: drawing the best weapon carried, hitting with it or with a bare fist, and putting the weapon away once things are calm.
- [`NpcTargeting`](../src/main/java/lifeblood/combat/NpcTargeting.java): Lets hostile mobs pick NPCs as targets, the same way they pick players.
- [`ThreatAssessment`](../src/main/java/lifeblood/combat/ThreatAssessment.java): A snapshot of how dangerous an NPC's surroundings are: the hostiles nearby, weighed against the NPC's own fighting strength plus that of its allies: NPCs its faction is allied with, and players it is personally allied with.

The /lb command tree: tools for admins, content and testing, never the way to play.

- [`CommandSupport`](../src/main/java/lifeblood/command/CommandSupport.java): What the /lb commands share: arguments and their suggestions, finding NPCs and people, and replying.
- [`CommandTree`](../src/main/java/lifeblood/command/CommandTree.java): How the /lb command tree describes itself.
- [`FactionCommands`](../src/main/java/lifeblood/command/FactionCommands.java): /lb faction: factions, their stances, relations, colors and members.
- [`FamilyCommands`](../src/main/java/lifeblood/command/FamilyCommands.java): Families and words.
- [`LifebloodCommand`](../src/main/java/lifeblood/command/LifebloodCommand.java): /lb, the one entry to every Lifeblood command.
- [`LookCommands`](../src/main/java/lifeblood/command/LookCommands.java): /lb look: how NPCs look: appearance parts, palettes and skin files.
- [`NpcCommands`](../src/main/java/lifeblood/command/NpcCommands.java): /lb npc: making NPCs and directing them, like vanilla commands do for entities: summon, list, remove, heal, teleport, plus orders (go to, follow, stay, wander, free), gender, how hard they are to kill, growing up, and saying a line.
- [`PersonalityCommands`](../src/main/java/lifeblood/command/PersonalityCommands.java): Who NPCs are and how they feel.
- [`PrefabCommands`](../src/main/java/lifeblood/command/PrefabCommands.java): /lb prefab: saving builds as prefabs and placing them, for making and testing the houses NPCs will live in.
- [`TargetArgument`](../src/main/java/lifeblood/command/TargetArgument.java): A command argument naming NPCs, or people (NPCs and players), the way vanilla commands name entities, plus NPC names.
- [`ToolCommands`](../src/main/java/lifeblood/command/ToolCommands.java): Tools for building and testing the mod rather than playing it.

## `dialogue`

Conversations: the menus and the options in them, gifts, romance talk, and NPCs asking for words.

- [`DialogueMenus`](../src/main/java/lifeblood/dialogue/DialogueMenus.java): The conversation menus and the options in them.
- [`DialogueOption`](../src/main/java/lifeblood/dialogue/DialogueOption.java): Something the player can say, and what happens when they say it.
- [`DialogueSession`](../src/main/java/lifeblood/dialogue/DialogueSession.java): An open conversation.
- [`DialogueSetup`](../src/main/java/lifeblood/dialogue/DialogueSetup.java): Puts the built-in options into the conversation menus, in steps of 100 so others can slot in between: chatting, gifts, romance, questions, following, and the practical menu (inventory, follow distance, fighting style).
- [`NpcConversation`](../src/main/java/lifeblood/dialogue/NpcConversation.java): Who the NPC is talking to right now, if anyone.
- [`NpcDialogue`](../src/main/java/lifeblood/dialogue/NpcDialogue.java): What an NPC says when a conversation reaches this point, and the replies the player can pick.
- [`NpcGifts`](../src/main/java/lifeblood/dialogue/NpcGifts.java): Giving an NPC whatever the player is holding: one of it goes into the NPC's inventory and is theirs from then on, to eat, wear or use.
- [`RomanceDialogue`](../src/main/java/lifeblood/dialogue/RomanceDialogue.java): The player's side of romance and family in conversation: asking someone out, proposing, the wedding, breaking up, answering when the NPC is the one asking, and asking about their family.
- [`SocialLimits`](../src/main/java/lifeblood/dialogue/SocialLimits.java): Pacing for making friends: one gift per NPC per in-game day, and five chats with an NPC per real-world minute.
- [`TextRequest`](../src/main/java/lifeblood/dialogue/TextRequest.java): What to ask the player to type: the question, a hint about what kind of answer fits ("A place name, like Greenhollow"), words shown before the box ("a", "some") so the player types just the word, a starting text, and an optional extra button.
- [`WordDialogue`](../src/main/java/lifeblood/dialogue/WordDialogue.java): NPCs asking the player for words: now and then, chatting with an NPC ("How are you?") turns into "What would you call a food you'd eat for breakfast?".

## `entity`

The NPC entity itself, the part system it's built from, and what any system may ask about an NPC.

- [`EntityNPC`](../src/main/java/lifeblood/entity/EntityNPC.java): A general-purpose NPC.
- [`NpcGender`](../src/main/java/lifeblood/entity/NpcGender.java): An NPC's gender.
- [`NpcPart`](../src/main/java/lifeblood/entity/NpcPart.java): A self-contained piece of an NPC (its life, health, eating...): its own state, its own upkeep, and its own section of the save.

- [`Persons`](../src/main/java/lifeblood/entity/Persons.java): Telling people (players and NPCs) apart from creatures, and finding who is really behind an attack.

## `event`

The event hub: what happens in the world (deaths, births, real attacks, gifts, couples changing), posted where it happens and heard by every system that subscribed.

- [`AttackedEvent`](../src/main/java/lifeblood/event/AttackedEvent.java): An NPC was attacked for real and hurt: not a brawl punch or a friend's shove (those are sorted out first).
- [`BirthEvent`](../src/main/java/lifeblood/event/BirthEvent.java): A child was born, to two NPCs or to an NPC and a player.
- [`BrawlEndedEvent`](../src/main/java/lifeblood/event/BrawlEndedEvent.java): A brawl ended with a winner: the loser gave in, or walked away (forfeit).
- [`DeathEvent`](../src/main/java/lifeblood/event/DeathEvent.java): Someone or something died: any mob, players and NPCs included, just before it's removed.
- [`GiftEvent`](../src/main/java/lifeblood/event/GiftEvent.java): A player gave an NPC something, and the NPC took it.
- [`LifeEvents`](../src/main/java/lifeblood/event/LifeEvents.java): The event hub: something happens (a death, a birth, a hit, a gift, a couple changing), the code where it happens posts an event, and every system that cares has subscribed to it.
- [`PartnershipEvent`](../src/main/java/lifeblood/event/PartnershipEvent.java): Two people's relationship changed: they started dating, got engaged, married, or split up.

Factions: who belongs to which, their colors, how factions regard each other, and how an NPC regards a person.

- [`FactionRegistry`](../src/main/java/lifeblood/faction/FactionRegistry.java): The factions of one world and how they regard others, saved with the world (BTA SavedData).
- [`FactionRelation`](../src/main/java/lifeblood/faction/FactionRelation.java): How two factions regard each other.
- [`NpcFactions`](../src/main/java/lifeblood/faction/NpcFactions.java): How an NPC regards another person, combining every layer: 1.
- [`NpcRelations`](../src/main/java/lifeblood/faction/NpcRelations.java): One NPC's personal feelings toward individual players.

## `family`

Families and growing up: kinship, romance, children, birth, age stages and birthdays.

- [`AgeStage`](../src/main/java/lifeblood/family/AgeStage.java): Where someone is in growing up, for how they talk: babbling babies (0–2), little kids (3–9), young teens (10–15), older teens (16–17) and adults.
- [`Children`](../src/main/java/lifeblood/family/Children.java): Married couples have children, so settlements carry on across generations.
- [`FamilyNames`](../src/main/java/lifeblood/family/FamilyNames.java): How family names pass down, the traditional way: a child takes its father's family name, and a bride usually takes her husband's at the wedding, remembering the one she was born with.
- [`FamilySetup`](../src/main/java/lifeblood/family/FamilySetup.java): A child keeping near a parent, as an instinct every NPC has (it only does anything while they're a child).
- [`Kinship`](../src/main/java/lifeblood/family/Kinship.java): What one person is to another, worked out from parents and partnerships: "Tom is Ann's brother".
- [`NpcLife`](../src/main/java/lifeblood/family/NpcLife.java): An NPC's life story so far: its family name, when it was born, how grown up it is, its birthdays, its graying hair, and where it's from.
- [`Romance`](../src/main/java/lifeblood/family/Romance.java): How couples form and change, for NPCs with each other and with players.
- [`StayNearParentBehavior`](../src/main/java/lifeblood/family/StayNearParentBehavior.java): A child keeps close to a parent who's around (an NPC or a player), toddling after them when they wander off and pottering about nearby otherwise.

## `following`

Following a player: the order itself, how closely, when an NPC leaves, and watching what the player does.

- [`FollowDistance`](../src/main/java/lifeblood/following/FollowDistance.java): How closely an NPC follows: it starts walking once the player is further than start, and stops within stop.
- [`FollowingSetup`](../src/main/java/lifeblood/following/FollowingSetup.java): The follow order, and followers heading home when the player they follow dies.
- [`FollowPlayerBehavior`](../src/main/java/lifeblood/following/FollowPlayerBehavior.java): Walks after a player, teleporting to them when left too far behind.
- [`NpcFollowing`](../src/main/java/lifeblood/following/NpcFollowing.java): Following a player: whether it will, how closely, leaving when it falls out with them, and keeping an eye on what they get up to.

## `gossip`

News and gossip: what happens in the world becomes news, people near it and the family of those involved know at once, and it travels by word of mouth in chats, coloring opinions of whoever it's about.

- [`Gossip`](../src/main/java/lifeblood/gossip/Gossip.java): How news starts and what hearing it does.
- [`GossipRegister`](../src/main/java/lifeblood/gossip/GossipRegister.java): The news of one world and who has heard each piece, saved with the world (BTA SavedData).
- [`GossipSetup`](../src/main/java/lifeblood/gossip/GossipSetup.java): News: what happens becomes news (see Gossip), and NPCs pass it on in chats (see GossipTopics).
- [`GossipTopics`](../src/main/java/lifeblood/gossip/GossipTopics.java): Passing news on: the "news" chat topic (fresh news the listener hasn't heard), the "old_news" one ("remember when...", for big news that's no longer fresh), and telling a player who asks.
- [`News`](../src/main/java/lifeblood/gossip/News.java): One piece of news: what kind, who it's about (and who else), when it happened, and the names to tell it with, kept so it can still be told once they're gone.
- [`NewsKind`](../src/main/java/lifeblood/gossip/NewsKind.java): Kinds of news people pass on.

## `health`

Health by the player's rules: health modes, being downed and recovering, and eating.

- [`HealthMode`](../src/main/java/lifeblood/health/HealthMode.java): Whether an NPC can be hurt and killed.
- [`HealthSetup`](../src/main/java/lifeblood/health/HealthSetup.java): Going home to recover after being downed, as an instinct every NPC has.
- [`NpcEating`](../src/main/java/lifeblood/health/NpcEating.java): Eating by the player's rules: only when hurt enough, picking the food it likes best, one bite at a time.
- [`NpcHealth`](../src/main/java/lifeblood/health/NpcHealth.java): How an NPC takes a beating: its health mode, and for invincible NPCs, being knocked down instead of killed, lying there a few seconds, then going home to recover.
- [`RecoverBehavior`](../src/main/java/lifeblood/health/RecoverBehavior.java): After being downed, the NPC goes home and stays there until it has recovered, whatever its orders were.

## `inventory`

What an NPC carries, as much as a player can, and the menu that shows it.

- [`NpcArmorSlot`](../src/main/java/lifeblood/inventory/NpcArmorSlot.java): Same rules as the player's armor slots (vanilla SlotArmor is tied to the player's own menu).
- [`NpcInventory`](../src/main/java/lifeblood/inventory/NpcInventory.java): Everything an NPC carries, as much as a player can: 4 armor slots (head, chest, legs, boots, matching HumanArmorShape order), the item in its hand, and 35 more slots, so 36 besides armor, like a player's inventory.
- [`NpcMenu`](../src/main/java/lifeblood/inventory/NpcMenu.java): The NPC's inventory on top, laid out like the player's own: armor column beside its preview, three rows of pack, and a bottom row that starts with the hand slot, like a hotbar.

## `mixin`

Changes to BTA's own classes, each named after its target and listed in lifeblood.mixins.json.

- [`ChunkLoaderMixin`](../src/main/java/lifeblood/mixin/ChunkLoaderMixin.java): Saves and loads each chunk's ownership records along with its blocks (every chunk format goes through here).
- [`ChunkMixin`](../src/main/java/lifeblood/mixin/ChunkMixin.java): Gives every chunk its ownership records, and keeps them up to date as blocks change.
- [`HudComponentCrosshairMixin`](../src/main/java/lifeblood/mixin/HudComponentCrosshairMixin.java): Hides the crosshair while talking to an NPC, since the player can't look around then.
- [`ItemStackMixin`](../src/main/java/lifeblood/mixin/ItemStackMixin.java): Blocks a player places by using an item on a block are theirs.
- [`MobDeathMixin`](../src/main/java/lifeblood/mixin/MobDeathMixin.java): Posts a DeathEvent whenever any mob dies (players included), so systems can react: witnesses, family, followers.
- [`MobGhastMixin`](../src/main/java/lifeblood/mixin/MobGhastMixin.java): Ghasts re-pick their target when they have none or every second; at those moments a visible NPC that is closer than any valid player becomes the target instead.
- [`MobMonsterMixin`](../src/main/java/lifeblood/mixin/MobMonsterMixin.java): Monsters (zombies, skeletons, creepers, snowmen...) hunt NPCs as well as players.
- [`MobScorpionMixin`](../src/main/java/lifeblood/mixin/MobScorpionMixin.java): Scorpions pick their own targets and are only hostile in the dark; same rule applies to NPCs.
- [`MobSlimeMixin`](../src/main/java/lifeblood/mixin/MobSlimeMixin.java): Slimes hop toward the nearest player; when an NPC is closer they hop toward it instead, using the same movement as vanilla MobSlime.updateAI.
- [`MobSpiderMixin`](../src/main/java/lifeblood/mixin/MobSpiderMixin.java): Spiders pick their own targets and are only hostile in the dark; same rule applies to NPCs.
- [`PathAccessor`](../src/main/java/lifeblood/mixin/PathAccessor.java): Exposes a path's steps, so the navigator can check them for hazards before following it.
- [`WorldTickMixin`](../src/main/java/lifeblood/mixin/WorldTickMixin.java): Runs the mod's world systems once per world tick, after the world's own upkeep.

## `nav`

Getting around: the world as walkable spaces, the path search, the shared per-tick budget, and walking a path.

- [`NavBudget`](../src/main/java/lifeblood/nav/NavBudget.java): Caps how much path searching all NPCs together may do in one tick, so a big fight where everyone replans at once spreads the work over a few ticks instead of stalling one.
- [`NavGrid`](../src/main/java/lifeblood/nav/NavGrid.java): The world as the pathfinder sees it: for each block space, whether someone with their feet in it could stand there, swim, climb, pass through in mid-air, or not fit at all.
- [`NavMove`](../src/main/java/lifeblood/nav/NavMove.java): How a path step is reached from the one before it.
- [`NavPath`](../src/main/java/lifeblood/nav/NavPath.java): A planned route, followed one step at a time.
- [`NavSearch`](../src/main/java/lifeblood/nav/NavSearch.java): A* search over NavGrid.
- [`NavStep`](../src/main/java/lifeblood/nav/NavStep.java): One step of a path: the block space the feet should reach, at what height, and how.
- [`NpcNavigator`](../src/main/java/lifeblood/nav/NpcNavigator.java): Movement for NPCs.

## `ownership`

Who placed each block, and who may use what someone owns.

- [`BlockOwners`](../src/main/java/lifeblood/ownership/BlockOwners.java): Who placed each block.
- [`ChunkOwners`](../src/main/java/lifeblood/ownership/ChunkOwners.java): Who owns the placed blocks in one chunk, saved with the chunk.
- [`OwnedChunk`](../src/main/java/lifeblood/ownership/OwnedChunk.java): Added to every chunk by a mixin: the records of who placed its blocks.
- [`Ownership`](../src/main/java/lifeblood/ownership/Ownership.java): Who shares what someone owns: themself, their husband or wife, their parents and their children.
- [`OwnershipSetup`](../src/main/java/lifeblood/ownership/OwnershipSetup.java): Forgetting, each tick, any placer left over by an action that never finished (see BlockOwners.placingAs).

## `people`

The register of everyone who has lived in the world, and the pool of names.

- [`NamePool`](../src/main/java/lifeblood/people/NamePool.java): The names NPCs are given, from assets/lifeblood/names.txt: [male] and [female] sections of given names and a [family] section of family names, one name per line, .
- [`PeopleRegistry`](../src/main/java/lifeblood/people/PeopleRegistry.java): Everyone who has lived in this world, saved with it: a record of each person (NPC or player) that outlasts their entity, so people who are far away, unloaded or dead still count.
- [`PeopleSetup`](../src/main/java/lifeblood/people/PeopleSetup.java): Keeping the register of people tidy, and recording deaths in it.

## `perf`

Measuring the mod's cost per tick, for /lb debug perf.

- [`NpcProfiler`](../src/main/java/lifeblood/perf/NpcProfiler.java): Measures how much time NPCs take, in one-second windows, for /lb debug perf.

## `personality`

Who an NPC is: trait axes, quirks, tastes, attraction, and how it takes to its surroundings.

- [`Attraction`](../src/main/java/lifeblood/personality/Attraction.java): Who an NPC can fall for, rolled once.
- [`ItemDefaults`](../src/main/java/lifeblood/personality/ItemDefaults.java): How much people like each item before personality comes into it: everyone loves a diamond and nobody wants a handful of dirt.
- [`NpcAwareness`](../src/main/java/lifeblood/personality/NpcAwareness.java): Noticing the world around it: remarking when the weather turns, the season changes or it walks somewhere new, and its mood following the weather and the place it's in.
- [`NpcPersonality`](../src/main/java/lifeblood/personality/NpcPersonality.java): Who an NPC is: eight trait axes, a few quirks, and tastes in food, things, weather and places.
- [`Quirk`](../src/main/java/lifeblood/personality/Quirk.java): Discrete traits that give an NPC its own topics, habits and opinions of others.
- [`Surroundings`](../src/main/java/lifeblood/personality/Surroundings.java): The weather, biome and season an NPC is in, as short keys ("storm", "desert", "winter"), with how much people like each before personality comes into it.
- [`TasteCategory`](../src/main/java/lifeblood/personality/TasteCategory.java): What kind of thing an item is, as far as people's tastes go.
- [`Tastes`](../src/main/java/lifeblood/personality/Tastes.java): How much an NPC likes things, from -1 (hates it) to +1 (loves it): every item, plus kinds of weather, biomes and seasons.
- [`TraitAxis`](../src/main/java/lifeblood/personality/TraitAxis.java): The core of an NPC's character: eight scales from -1 to +1.
- [`TraitTier`](../src/main/java/lifeblood/personality/TraitTier.java): How far toward a pole a trait value sits.

## `social`

Feelings about people: memories, opinions, compatibility, and dealings with particular people.

- [`Compatibility`](../src/main/java/lifeblood/social/Compatibility.java): How one NPC's traits make it regard someone else's, before anything has happened between them.
- [`Memory`](../src/main/java/lifeblood/social/Memory.java): One thing an NPC remembers: what happened, who did it (if anyone), when, and how strongly it was felt.
- [`MemoryType`](../src/main/java/lifeblood/social/MemoryType.java): Kinds of things an NPC remembers.
- [`NpcMemories`](../src/main/java/lifeblood/social/NpcMemories.java): Everything an NPC remembers, and what those memories add up to: its opinion of each person and its mood.
- [`NpcSocial`](../src/main/java/lifeblood/social/NpcSocial.java): The NPC's dealings with particular people: who saved its life, the daily gift each player has given, and anything it's waiting to ask a player (out on a date, or to marry).
- [`Opinions`](../src/main/java/lifeblood/social/Opinions.java): What an NPC thinks of someone, from -100 to +100: its memories of them plus standing factors (faction ties, family, and personality compatibility).
- [`SocialEvents`](../src/main/java/lifeblood/social/SocialEvents.java): How NPCs react to a death (a DeathEvent listener, see SocialSetup): witnesses thank whoever helped, count rescues, grieve and hold grudges against killers, and the dead person's family grieves wherever they are.
- [`SocialSetup`](../src/main/java/lifeblood/social/SocialSetup.java): How people react to deaths around them and in their family (see SocialEvents).

## `speech`

What NPCs say: the line library read from .speech files, the facts lines can use, speech styles, and the voice.

- [`ChatTopic`](../src/main/java/lifeblood/speech/ChatTopic.java): Something two NPCs can chat about: the weather, food, home, the news.
- [`ChatTopics`](../src/main/java/lifeblood/speech/ChatTopics.java): The topics NPCs chat about: the built-in ones (the weather, food, home, and general chat, which includes family), plus any another system registers from its setup.
- [`Condition`](../src/main/java/lifeblood/speech/Condition.java): One requirement on a line in a speech file, written in the braces at its end: a pole ("polite": leaning that way or more, "polite+": strongly), a quirk ("glutton"), or a fact ("time=night").
- [`NpcVoice`](../src/main/java/lifeblood/speech/NpcVoice.java): An NPC's voice: its speech style, what it said recently, and when it speaks up on its own, whether greeting players, remarking on things, or chatting with other NPCs.
- [`SpeechContext`](../src/main/java/lifeblood/speech/SpeechContext.java): Everything a line can depend on at the moment an NPC speaks: who's speaking and to whom, the facts of the moment ("time" = "night"), and the words lines can mention ([favorite_food]).
- [`SpeechEngine`](../src/main/java/lifeblood/speech/SpeechEngine.java): Turns a symbol into a sentence: picks one of its lines that fits the moment, then fills in every [name] inside it, recursively.
- [`SpeechFacts`](../src/main/java/lifeblood/speech/SpeechFacts.java): Gathers the facts of the moment for a line: who's talking to whom and how they feel about them, the time and weather, the speaker's mood and health, faction, tastes and voice.
- [`SpeechLibrary`](../src/main/java/lifeblood/speech/SpeechLibrary.java): Every line NPCs can say, loaded from speech files: the ones bundled with the mod, plus any .speech files in the game folder's npc_speech directory (added on top, so new lines can be written without rebuilding).
- [`SpeechStyle`](../src/main/java/lifeblood/speech/SpeechStyle.java): The surface of an NPC's voice, independent of personality, so two NPCs with the same traits still sound different: what they call people, a catchphrase, a filler they tack on, and habits like dropping g's.
- [`Word`](../src/main/java/lifeblood/speech/Word.java): A noun that knows its forms, so sentences agree with it: "a pork chop", "some blackberries", "some bread".

## `util`

Small helpers shared by several systems that belong to none of them.

- [`Geometry`](../src/main/java/lifeblood/util/Geometry.java): Small geometry helpers shared by several systems: for now, whether a line passes through a box (line of fire).

## `words`

The word book: words players teach NPCs, and who knows them.

- [`WordBook`](../src/main/java/lifeblood/words/WordBook.java): Every word players have taught NPCs, saved with the world.
- [`WordCategory`](../src/main/java/lifeblood/words/WordCategory.java): What kind of word the player is teaching, which decides how it's asked for and how it's used.

## `world`

The world's own clock and calendar, and systems that run per world whether or not an NPC is near.

- [`Calendar`](../src/main/java/lifeblood/world/Calendar.java): Days, years and dates for ages and birthdays, following the world's own seasons: an overworld year is four 14-day seasons, 56 days.
- [`WorldSystem`](../src/main/java/lifeblood/world/WorldSystem.java): Something that runs for a whole world on its own clock, whether or not any NPC is nearby: keeping registers tidy now, and later elections, wars, trade between towns, and time passing for people who aren't loaded.
- [`WorldSystems`](../src/main/java/lifeblood/world/WorldSystems.java): The world systems, run from each world's tick (see the world tick mixin).
